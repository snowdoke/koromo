# `layout.html` のテンプレート変数について

`src/layout.html` では、`{{ title }}` や `{{ header }}` のようなテンプレート変数を使って、ビルド時にページごとの内容や共通パーツを差し込みます。

## 基本的な考え方

`layout.html` は、全ページ共通のHTML構造を定義するレイアウトファイルです。

各ページのHTMLは、この `layout.html` に差し込まれて、最終的に `dist/` に出力されます。

```html
<!doctype html>
<html lang="ja">
<head>
  <meta charset="utf-8">
  <title>{{ title }}</title>
</head>
<body>
  {{ header }}

  {{ content }}

  {{ footer }}
</body>
</html>
```

ビルド時に、`{{ ... }}` の部分が実際の値に置き換わります。

---

## `{{ title }}`

ページのタイトルを出力します。

各ページのfront matterに書いた `title` が入ります。

```html
---
title: About
---
```

`layout.html` 側では、以下のように使います。

```html
<title>{{ title }}</title>
```

出力結果は以下のようになります。

```html
<title>About</title>
```

---

## `{{ description }}`

ページの説明文を出力します。

各ページのfront matterに書いた `description` が入ります。

```html
---
description: 私たちについてのページです。
---
```

`layout.html` 側では、以下のように使います。

```html
<meta name="description" content="{{ description }}">
```

出力結果は以下のようになります。

```html
<meta name="description" content="私たちについてのページです。">
```

---

## `{{ header }}`

共通ヘッダーを出力します。

`src/partials/header.html` の内容が、この位置に差し込まれます。

```html
{{ header }}
```

例えば `src/partials/header.html` が以下の場合、

```html
<header class="site-header">
  <h1><a href="/">My Site</a></h1>
  <nav>
    <a href="/">Home</a>
    <a href="/about/">About</a>
  </nav>
</header>
```

出力結果では、`{{ header }}` の位置にそのまま挿入されます。

---

## `{{ content }}`

各ページの本文を出力します。

front matterを除いた本文部分が、この位置に差し込まれます。

```html
{{ content }}
```

例えば `src/pages/about.html` が以下の場合、

```html
---
title: About
description: 私たちについてのページです。
---

<main class="about">
  <h1>About</h1>
  <p>Aboutページです。</p>
</main>
```

`{{ content }}` には以下の部分が入ります。

```html
<main class="about">
  <h1>About</h1>
  <p>Aboutページです。</p>
</main>
```

---

## `{{ footer }}`

共通フッターを出力します。

`src/partials/footer.html` の内容が、この位置に差し込まれます。

```html
{{ footer }}
```

例えば `src/partials/footer.html` が以下の場合、

```html
<footer class="site-footer">
  <small>&copy; My Site</small>
</footer>
```

出力結果では、`{{ footer }}` の位置にそのまま挿入されます。

---

## `{{ faviconTags }}`

favicon関連のタグを出力します。

サイト共通設定として、すべてのページに同じfaviconを読み込ませます。

```html
{{ faviconTags }}
```

出力例：

```html
<link rel="icon" href="/assets/img/favicon.ico">
<link rel="apple-touch-icon" href="/assets/img/apple-touch-icon.png">
```

---

## `{{ ogTags }}`

OGP用のmetaタグを出力します。

`title`、`description`、`snsImage` をもとに、SNS共有用の情報を生成します。

```html
{{ ogTags }}
```

出力例：

```html
<meta property="og:title" content="About">
<meta property="og:description" content="私たちについてのページです。">
<meta property="og:type" content="website">
<meta property="og:url" content="https://example.com/about/">
<meta property="og:image" content="https://example.com/assets/img/ogp.jpg">
```

---

## `{{ twitterCardTags }}`

Twitter Card用のmetaタグを出力します。

`title`、`description`、`snsImage` をもとに生成します。

`twitter:card` は `summary_large_image` 固定です。

```html
{{ twitterCardTags }}
```

出力例：

```html
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:title" content="About">
<meta name="twitter:description" content="私たちについてのページです。">
<meta name="twitter:image" content="https://example.com/assets/img/ogp.jpg">
```

---

## `{{ externalCssTags }}`

ページ個別で読み込む外部CSSを出力します。

front matterに `externalCss` を指定した場合だけ出力されます。

```html
---
externalCss: https://cdn.example.com/library.css
---
```

`layout.html` 側では、以下のように使います。

```html
<link rel="stylesheet" href="/assets/css/style.css">
{{ externalCssTags }}
```

出力例：

```html
<link rel="stylesheet" href="/assets/css/style.css">
<link rel="stylesheet" href="https://cdn.example.com/library.css">
```

指定がない場合、何も出力されません。

---

## `{{ externalJsTags }}`

ページ個別で読み込む外部JSを出力します。

front matterに `externalJs` を指定した場合だけ出力されます。

```html
---
externalJs: https://cdn.example.com/library.js
---
```

`layout.html` 側では、以下のように使います。

```html
<script src="/assets/js/main.js" defer></script>
{{ externalJsTags }}
```

出力例：

```html
<script src="/assets/js/main.js" defer></script>
<script src="https://cdn.example.com/library.js" defer></script>
```

外部JSには自動で `defer` が付きます。

指定がない場合、何も出力されません。

---

## `layout.html` の例

```html
<!doctype html>
<html lang="ja">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">

  <title>{{ title }}</title>
  <meta name="description" content="{{ description }}">

  {{ faviconTags }}
  {{ ogTags }}
  {{ twitterCardTags }}

  <link rel="stylesheet" href="/assets/css/style.css">
  {{ externalCssTags }}
</head>
<body>
  {{ header }}

  {{ content }}

  {{ footer }}

  <script src="/assets/js/main.js" defer></script>
  {{ externalJsTags }}
</body>
</html>
```

---

## 使用できる主なテンプレート変数

| 変数                      | 内容                  |
| ----------------------- | ------------------- |
| `{{ title }}`           | ページタイトル             |
| `{{ description }}`     | ページ説明文              |
| `{{ header }}`          | 共通ヘッダー              |
| `{{ content }}`         | ページ本文               |
| `{{ footer }}`          | 共通フッター              |
| `{{ faviconTags }}`     | favicon関連タグ         |
| `{{ ogTags }}`          | OGP用metaタグ          |
| `{{ twitterCardTags }}` | Twitter Card用metaタグ |
| `{{ externalCssTags }}` | ページ個別の外部CSS         |
| `{{ externalJsTags }}`  | ページ個別の外部JS          |

---

## 注意点

`{{ ... }}` の名前は、`scripts/build.js` 側で渡している名前と一致している必要があります。

例えば、`scripts/build.js` で `title` として渡している場合、

```html
{{ title }}
```

は置き換わります。

しかし、以下のように別名にすると置き換わりません。

```html
{{ pageTitle }}
```

テンプレート変数を追加したい場合は、`layout.html` に書くだけでなく、`scripts/build.js` 側でも同じ名前の値を渡す必要があります。
